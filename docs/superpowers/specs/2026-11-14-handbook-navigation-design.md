- 首頁：定位、問題導向入口、主題地圖、閱讀路線與精選。
- 分區 README：完整文章索引，保留現有檔名與路徑。
- Embedded：新增可勾選的分階段主題清單，與已完成文章分開。
- 現有技術本文、程式碼、PDF 不變；現有工具 README 僅修正失效導覽。
- 不更名遠端 GitHub repository、不提交、不推送。

## Approaches

1. 只補首頁：成本低，但子目錄仍難查找。
2. 首頁＋分區索引：使用者已同意，保留路徑並建立兩層入口。
3. 搬移文件或建立網站：額外的連結與部署維護，這次不採用。

## 驗收

新增導覽連結可解析；主要分區文章都有入口；待補主題不冒充已完成文件；技術本文與使用者既有變動維持原樣。
